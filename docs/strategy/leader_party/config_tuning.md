# Configuration tuning

The preferred bot is `leader_party_tuned`, matching frozen **`g07_search`**. It combines the selected settings in one C++ bot using Subhan’s camp-loop planner. Original bots and every tuning generation remain intact.

The final bot scored **409–107** against untuned Subhan, D1 and gold_diamond across all 86 published maps, and **178–2** in the separate wider suite.

See the [complete tuning report](config_tuning_all_stats.md) for all settings, generation comparisons, methodology, evidence and limitations. [Initial G2 results](config_tuning_first_pass.md) remain as history.
