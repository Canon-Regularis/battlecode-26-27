# E37 — Elkring-gated Jungle Strength purchase

Based on E05A. On the official map pool, the SDK reports Elkring as 30×30; all eight other maps have different dimensions. On that map only, Cassi and Issac buy Strength Jungle shards until one Jungle Strength emblem is complete, then resume the existing Power Strength shard. On all other maps the purchase rule remains E05A's Power Strength rule. No combat, navigation, banking, or regroup logic changes.

The E36 full matrix showed the Jungle purchase improving Elkring's score differential against all four tested opponents, while its overall results were mixed across the map pool. E37 tests the simple width/height gate at `--fuel 100000` (2,500,000 Python fuel). This is local-only; G2 remains protected.
